# The logarithmic correction to the relaxation time of the two-dimensional Fredrickson-Andersen one-spin facilitated model

Yitzchak Shmalo

For the Fredrickson-Andersen one-spin facilitated model on Z^2 with density q of empty sites, we prove that the spectral gap is at most (320/9) q^2 / H_R, where H_R is the harmonic number of R = floor(1/(4 sqrt q)). Together with the lower bound of Cancrini, Martinelli, Roberto and Toninelli, this shows that the relaxation time is of order q^(-2) log(1/q) as q -> 0, which is Conjecture 4.3 in the monograph of Hartarsky and Toninelli. The test function is H_R^(-1) sum_{r <= R} K_r / r, where K_r is the number of clusters of the graph on the empty sites of a box in which two empty sites are adjacent when their l^1 distance is at most r.
